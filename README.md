# 👗 Wearify – Hyperlocal Clothing Rental & Purchase Platform

Wearify is a hyperlocal fashion platform where users can **rent or buy clothes from nearby shops** with doorstep delivery.

---

## 🚀 Features
- 👤 User authentication (JWT based login/register)
- 🛍️ Browse products from local shops
- 🛒 Add to cart functionality
- 📦 Order placement system (in progress)
- 🔐 Secure APIs with Spring Security
- 👕 Rent or Buy options for products

---

## 🛠️ Tech Stack
- Backend: Java, Spring Boot, Spring Security, JWT
- Database: MongoDB
- Frontend: HTML, CSS, JavaScript (Vite)
- API Testing: Postman

---

## 📂 Project Structure

Wearify/
│── wearify_backend/ → Spring Boot backend
│── wearify-frontend/ → Frontend (UI)
